# 物語・世界観

※SF作品風ですが、少なくとも現時点では壮大な物語を含める予定はありません。

宇宙を旅するあなた（プレイヤー）は、宇宙船の不具合により未知の惑星に降り立ちました。
自身が乗っていた宇宙船の本体は惑星のどこかにありますが、自身の小さな脱出ポッドとは別の場所に降り立ったようです。
そこで、あなたは未知の惑星を探索して星からの脱出を目指します。

未知の星には先住生命体 (indigenous life) がおり、概してプレイヤーに敵対的です。
プレイヤーは先住生命体の攻撃をしのぎ、時にはその巣を破壊しながら、自身の宇宙船を見つけ出し、修理して、惑星から脱出しなければなりません。

あなた自身も脱出ポッドの外に出て簡単な探索を行えますが、人の肉体で出来ることには限りがあります。
先住生命体は強力で、概して脱出ポッド外ではあなた自身が台頭に闘えることはないことに早々に気づくことになります。

幸い、脱出ポッドにはテラフォーミング用のロボット作成プログラムと、ごく初歩的なロボット作成レシピがインストールされていました。
ロボットには探索用、防御用といったいくつかのカテゴリがあり、資源を惑星から調達すれば脱出ポッドの付随装置でいくらか作れます。
しかし、より遠くを探索できたり、あるいは強力な武器を内蔵するロボットには資源もレシピも足りません。
あなたはロボットを駆使して、ごく稀には自分自身でも惑星を探索して、目標を達成するのです。
