# git及びGitHub操作に関するガイドライン

## git操作

gitコミットを作成する際には原則として日本語でコミットを作成してください。
そのソフトウェア上の大域的な意図について「XXXする」という形式で1行説明とともに同じくアプリケーションや
ゲーム上の意図に近い説明を行い、その後に必要に応じて技術的詳細を記述します。

「特定のファイルを修正した」はソースコードの差分から明らかですので、それが重要な意味であるとか、
それが唯一の可能なコミットの説明（例えば定数名をタイポ修正のため一つ変えるだけの場合など）でなければ控えてください。

絵文字は作業に直接関係する以外の装飾的な目的では控えます。
すなわち「📋️重要事項」といったAIエージェントが採択しがちな補足的利用はしません。

AIエージェントがコミットを作成したことを大々的に吹聴する必要はありません。

## GitHub

リモートリポジトリとして `git@github.com:dmiyakawa/in-the-search.git` を使用しています。
このソフトウェアに関係しない、他のリポジトリへのgitアクセスは許可されません。

ほとんどの指示ではGitHubリポジトリを意識する必要はないはずですので、同様に`gh`コマンドでの操作は通常の指示下では非推奨です。
GitHubのIssues等も現時点では活用していないため、GitHubにしかない情報と連動した作業は明示されていない限りは発生しないはずです。
