# 作業記録ガイドライン

`YYYYMMDD_NNN` というフォーマットの文字列を**タスクID**とします。
`NNN`は各作業日で一意の連番で`001`から始まります

各作業はタスクIDごとにファイル名のプレフィクスで大まかにグループ化されます。
タスクID `YYYYMMDD_NNN_` の後に半角のアルファベットと数字、`_`等を用いて可読可能なタスクの概要をファイル名に含め、
その後に作業のタイプや拡張子を含めます

例1: `20260620_001_first_investigation.request.md` ... タスクID `20260620_001` のFirst Investigationに関する作業指示のファイル

作業のタイプについては必要に応じて追加して構いませんが、下記においては一貫することを推奨します

- `request` ... そのタスクIDの（最初の）作業指示
- `result` ... そのタスクIDの作業記録（`result` であるのは標準的なファイルソート順序で `request` の後に並ぶようにするため）

各作業ではタスクIDを付与することが出来ます（AIエージェントへの指示においてはしばしば指示者から指定されることがあります）
その際には、指示の終了時には作業記録を残すことが期待されます。
一つの作業で複数の指示が連続して与えられた場合、同じ作業記録に追加指示と追加の作業記録追記していくことが望ましいです。
