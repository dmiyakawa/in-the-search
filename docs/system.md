# システム・ソフトウェア要求

## 動作環境の想定

- Webブラウザ上で動作するアプリケーションで、基本的なゲームエンジンはすべてJavaScriptやHTMLのレイヤで完結する
- デプロイ先はUbuntu 24.04 LTSのApache 2上を想定する
- ローカル開発環境ではDocker Composeで動作確認を行えるようにする

## ソフトウェア開発時のルール

- クリーンアーキテクチャを採用し、ゲームロジック（≒ビジネスロジック）をUI表現と可能な限り分離する（サービス層）
- テスト駆動開発を念頭に、ユニットテストを積極的に記述する
- vitestといったユニットテストフレームワークを使用してコードカバレッジを計測し、80%以上を維持する
- ユニットテストに加えて、前掲のクリーンアーキテクチャのゲームロジック（サービス層）に対する結合テストとブラウザ (playwright等) によるE2Eテストも積極的に導入する
