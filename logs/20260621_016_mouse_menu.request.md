# 操作可能ユニット、選択ユニットで出来る操作選択肢の明示、マウスでクリック可能なメニューの作成

現在自分と相手ユニットがどのような状況にあり、何が出来るかを明示し、また可能な操作はマウスから決定可能なメニューを作成してください。

以下に概略を示すので必要な設計変更や作業リスト更新を行います。
現在 todos.md には完了済のタスクのみがあるはずですので、一旦作業済のタスクについてすべて削除して、
本件で実装すべき項目が最優先事項となるように整理するのが望ましいです。

以下に行いたいことをより細かく説明します。不確定な部分は適宜指示者に問い合わせる、もしくは tbd.md に記載の上報告してください。

画面の左下範囲にユニット一覧とステータス、右下範囲に可視出来ている敵ユニット一覧とステータスを表示します。
現在のHPと、そのターン終了時のHP遷移や死亡の有無をそこに表示します。
自ユニットでは可能な行動数を明示し、行動が枯渇した場合にはそれと分かるようにします（グレーアウト等が有効です）
また、各ユニットのその説明はクリック可能とし、クリック時にそのユニットを選択できるようにもします

選択したユニットで可能な行動をユニット右上部にマップに被せるように不透明な行動メニューとして表示します。

基地上にある場合にはロボット作成の選択肢を、資源上では採掘の選択肢を表示するようにします。
実際にその行動が可能な場合（資源がある、資源が獲得できる状況にある）はそれらはクリック可能に、そうでない場合は無効の表示にすることで
マス上で理屈上行動できることと、そのターンで出来るかどうかを同時にメニュー上で表現します。

クリックをユニット外のマス目で行った際にユニットの選択が外れてメニューが非表示になるようにもし、
可視範囲にある敵ユニットをクリックした際にはそのユニットが右下の敵ユニット一覧のどれであるかを強調表示するようにします
（敵ユニットも選択可能にする）

ターン終了のボタンも表示します。
各ボタンに対応するショートカットキーがあるときには (G) のような表記で選択肢に表示します
