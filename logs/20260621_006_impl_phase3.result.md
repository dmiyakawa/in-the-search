## 実装内容

### `src/infrastructure/rng/SeededRng.ts`

- `SeededRng` interface と `createRng(seedOrState)` を実装。
- mulberry32 ベースで `nextU32` / `nextFloat` / `nextInt` / `getState` を提供。
- `nextInt` は正の整数以外を拒否。

### `src/infrastructure/mapgen/MapGenerator.ts`

- `GenResult` / `sampleN` / `generateMap` を実装。
- `MAP_RADIUS` 等の定数を `domain/units/stats.ts` から参照。
- pod は `{ q: 0, r: 0 }` 固定、goal は距離条件を満たす passable タイルから決定的に選択。
- 巣・敵・資源は同一 pool から順に非復元抽出し、重複しないよう配置。
- pod→goal が到達不能な場合は同一 RNG ストリームを継続して再試行し、上限後は `hexLine` による決定的 corridor carve で到達可能性を保証。
- テスト補助として `bfsReachable` / `carveCorridor` も export。

### `src/infrastructure/storage/StoragePort.ts`

- `StoragePort` interface と `LocalStoragePort` を実装。
- `save` は `JSON.stringify` で `localStorage` へ保存、`load` は存在しない slot で `null` を返す。

### `src/application/GameService.ts`

- `newGame(seed)` を仮の半径3マップから `generateMap(seed)` 利用へ差し替え。
- 初期状態に player / enemies / nests / generated map を反映し、初期視界を更新。
