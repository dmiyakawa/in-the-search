## サブエージェントレビューと反映

レビュー結果を MUST/SHOULD/NICE に分類し、MUST はすべて、合理的な SHOULD/NICE も反映した。

### MUST（反映済み）

- **`.gitignore` 整備**: ビルド成果物・依存・カバレッジ等を無視するよう追加。
- **`vitest.config.ts` に `coverage.all: true` を追加**: 未 import ファイルもカバレッジ集計に含め、D-10 の 80% 閾値が形骸化するのを防ぐ。

### SHOULD（反映済み）

- **`tsconfig.json` から `declaration`/`declarationMap` を削除**: ブラウザアプリでは不要。
- **config ファイルも型付き lint 対象に**: `tsconfig.eslint.json` を新設し、`.eslintrc.json` の `parserOptions.project` をそちらに向ける。`@types/node` を追加して `process.env` の型を解決。
- **`package.json` の format 対象に `.eslintrc.json` を追加**。
- **`src/domain/resource/index.ts` を作成**: `design.md §4` のディレクトリ構成に合わせた。

### NICE（反映済み）

- **`vite.config.ts` に `preview.port: 4173` を追加**: E2E とローカル preview のポートを統一。
- **`playwright.config.ts` の `webServer.timeout` を 120000ms に設定**。
