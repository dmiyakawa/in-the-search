## 指示の要旨

- 自相で敵を倒せるとき、敵の描画を即座になくすだけでなく、X マーク等で「倒せる」ことを明示する。
- 右下パネルでは HP 遷移が `0/max` になる表示を残し、その敵がこのプレイヤー相で倒れると分かるようにする。
- ロボットや自キャラが敵相で倒れる場合も同様に、倒れる予定の強調を維持する。

## 実装内容

- `AttackIndicator` に攻撃対象の種類、攻撃前 HP、攻撃後 HP、撃破予定フラグを追加。
- プレイヤー攻撃で敵/巣が撃破予定の場合、Canvas 上の対象位置に X 印を重ねて表示するようにした。
- 右下敵パネルは、撃破済みで `GameState.units` から消えた敵でも直近攻撃表示から行を復元し、
  `HP before/max -> 0/max` と `Down this phase` を表示するようにした。
- 敵相プレビューで自ユニット/Pod が `DOWN` になる場合、左下パネルの該当行へ赤系強調と `Down this enemy phase` を追加。
- E2E に一撃撃破用シナリオ `?__scenario=ui-kill&__test=1` を追加し、撃破予定行が残ることと Undo 後に通常表示へ戻ることを検証。
- `design.md` と `todos.md` を実装後の挙動へ追従更新。
