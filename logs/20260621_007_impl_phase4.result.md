## 実装内容

### `src/presentation/CanvasRenderer.ts`

- `View` 型と `render(ctx, state, view)` を実装。
- pointy-top hex を `hexToPixel` に基づいて Canvas 2D に描画。
- `unknown` は背景扱い、`discovered` は減光、`visible` は通常色で描画。
- pod / goal / nest / 資源をタイル上に重畳。
- 自ユニットは常時描画し、敵と巣は visible タイル上のみ描画。

### `src/presentation/InputController.ts`

- `createInputController(canvas, service, getView)` を実装。
- canvas click を CSS ピクセル基準で補正し、`pixelToHex` で対象hexへ変換。
- Phase 4 の暫定仕様として、操作対象はプレイヤー本体（`player`）に固定。
- 隣接 visible 敵/巣へのクリックは `AttackUnit`、隣接 passable タイルへのクリックは `MoveUnit` を発行。
- 矢印キーで隣接移動、`E` キーで `EndTurn` を発行。

### `src/presentation/Hud.ts`

- `renderHud(root, state)` を実装。
- ターン、フェーズ、プレイヤーHP、残移動力、資源、状態、操作ヒントを表示。

### `src/main.ts`

- `?seed=` を読み、未指定時は `20260621` で決定的に起動。
- `GameService.newGame(seed)` / `subscribe` / Canvas renderer / HUD / InputController を配線。
- window resize 時に canvas サイズと view を再計算して再描画。

### その他

- `index.html` の HUD に `white-space: pre-line` を追加。
- `tests/e2e/smoke.spec.ts` で Phase 4 HUD 表示を確認する期待値を追加。
- `todos.md` に Phase 4 主要実装完了を反映。
